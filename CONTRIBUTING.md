# Contributing

Thank you for contributing to a Momi Ventures repository.

## Working norms

- Keep changes focused and reviewable.
- Include tests or deterministic validation when practical.
- Describe what changed, why it changed, and how it was verified.
- Prefer reversible changes and document rollback when risk is material.
- Do not commit credentials, secrets, private keys, protected health information (PHI), customer data, or other sensitive material.
- Keep generated binaries and large media out of normal Git history unless the repository explicitly requires them.

Repository-specific instructions take precedence over these defaults.
