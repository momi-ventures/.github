# Momi Ventures

Momi Ventures builds practical software for **AI automation, privacy, and developer productivity**.

We focus on making capable AI systems easier to use, more durable, and more useful in real workflows while keeping users in control of their data and tools.

Current work includes:
- **Secretary** — orchestration and capability management for AI-assisted work.
- **EasyDeID** — privacy-focused de-identification tooling.
- **ChartPaste** — reliable formatting and workflow tooling for clinical software.

Learn more at **https://momiventures.com**.
