# Security Policy

Please handle security-sensitive information carefully.

- Do **not** place credentials, secrets, private keys, PHI, customer data, or exploit details in public issues.
- For a security concern in a repository that supports GitHub private vulnerability reporting, use that private channel.
- Otherwise, contact Momi Ventures through https://momiventures.com and identify the affected repository.

We appreciate responsible reports that include a concise impact description, reproduction information when safe, and suggested mitigations if known.
